# Airbnb Price Prediction

A machine learning project for predicting Airbnb listing prices in Amsterdam.

## Project Status

🚧 Work in Progress

## Objective

The goal of this project is to build a machine learning model that predicts
Airbnb listing prices based on relevant listing, host, location, review,
and availability features.
